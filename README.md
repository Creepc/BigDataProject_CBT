# BigData Midterm Lab

「AI 기반 빅데이터 프로젝트」 중간고사 범위를 학습하기 위한 개인 CBT입니다. 기존 7개 PDF와 교수님 최종 1~3장 정리 PDF를 페이지 단위로 검토해 개념, 출처, 문제, 선택지별 해설을 연결합니다.

[학습 사이트 열기](https://creepc.github.io/BigDataProject_CBT/)

## 콘텐츠 규모

- PDF 8개, 전체 336쪽 확인 및 페이지별 색인 336건
- 핵심 개념 110개, 4지선다 문항 1,116개(단일 756개·복수 360개, 기존 996개 보존 + 중간 난도 120개 추가)
- 서로 겹치지 않는 신규 40문항×5회 고정형 실전 모의고사, 회차별 50분 시험·무제한 해설 학습
- 최종 PDF·구술 필기 기반 별도 40문항×3회: 어려움 84개·보통 36개, 핵심 108개·표시된 보충 12개
- 추가 기본 다지기 40문항×3회: 쉬움 60개·보통 60개, 전부 핵심 시험 범위. 기존 고난도와 별도로 선택
- 추가 중간 난도 40문항×3회: 전부 보통 난도 120개, 핵심 시험 범위. 기존 기본·고난도 240문항 유지
- 모든 개념에 기초·원리·적용·종합 4단계 문제와 학습 목표 330개의 직접 연결
- 개념별 상세 학습 본문 110개, 단계별 풀이 110개, 근거형 자가 점검 220개
- 실제 실행 결과를 검증한 Python 예제 21개
- 시각자료 해석 문항 133개(재구성 차트 123개·원본 강의 슬라이드 10개)
- 단원별 복습용 암기 카드 131개

시험 범위는 Netflix까지입니다. 별도 Titanic 실습은 학습·출제·복습·통계에서 제외합니다. `analysis/exam-scope.json`에 제외 항목과 페이지를 명시하며, 원본 PDF의 19·20·23쪽은 범위 밖, 18·21·22쪽은 Netflix 부분만 반영합니다.

- 학습 목표·선수 용어·원리 설명·풀이 예제·비교·오개념·자가 점검을 한 흐름으로 읽는 개념 학습
- 개념 본문·예제 검색, 예상 학습 시간, 목차 이동, 이전·다음 개념과 원문 PDF 페이지 연결
- 단일 정답과 복수 정답을 지원하는 4지선다 문제은행
- 110개 개념별 4문항 학습 코스, 전체 코스 이어 풀기, 풀이 수·최근 정답 수 구분
- 전체 문제의 자료·단원·개념·난이도·유형·상태 필터와 36문항 단위 페이지 이동
- 그래프 종류·의미·기울기·다변수 해석을 포함한 복합 문항
- 재구성 차트와 원본 강의 슬라이드를 함께 사용하는 시각자료 판독 문항
- 답안 제출 뒤 네 선택지의 용어 뜻·계산·판단 이유를 짧게 설명하는 해설
- 출제 범위·문항 수·시간·난이도 비율·무작위 순서를 조절하는 모의고사
- 고정형 실전 모의고사 5회, 신규 200문항 전부에 개념·단계별 풀이·주의점·다른 적용 사례 포함
- 회차별 최근·최고 점수, 제출한 시험 답안·해설 다시 열기, 40문항 학습 이동 및 미응답부터 이어 풀기
- 오답 누적 기록, 최근 정답 여부, 복습 완료 상태, 취약 개념 분석
- 암기 카드, 학습 진도, 북마크, 기록 내보내기·가져오기
- 브라우저 `localStorage` 기반 영구 저장과 라이트/다크 모드
- GitHub Pages용 자동 배포 워크플로

## 문제로 공부하는 순서

1. 문제은행의 **개념별 학습 코스**에서 전체 코스를 시작하거나 공부할 개념을 고릅니다.
2. 기초 → 원리 → 적용 → 종합 순서로 풀고, 제출 후 선택지별 뜻·이유와 핵심 개념 복습을 읽습니다.
3. 풀이 완료와 정답 수는 별개입니다. 틀린 문제는 오답노트에서 다시 풀어 확인합니다.
4. 전체 문제은행과 모의고사에서 순서를 바꿔 연습합니다. 제공된 범위의 학습을 돕는 코스이며 실제 시험 점수를 보장하지 않습니다.

## 신규 실전 모의고사

`실전 모의고사` 상단에서 1~5회를 고릅니다. 기존 556문항을 다시 추출한 것이 아닌 신규 200문항이며, 다섯 회차에 같은 문항을 재사용하지 않습니다. 200문항 전체가 시험 범위 110개 개념에 직접 연결됩니다.

- **시험 응시**: 회차별 고정 40문항·50분·문항당 2.5점, 제출 전 정답 비공개, 제출 후 전 문항 상세 해설. 복수 정답은 정답 전체를 선택해야 맞습니다.
- **해설 학습**: 시간 제한 없이 한 문제씩 제출해 관련 개념과 실제 풀이 과정을 읽습니다. 40문항 바로가기와 지난 응답의 해설 재열기를 지원합니다.
- **진행과 기록**: 문항 응답은 학습·시험의 최근 답안을 함께 반영하되 빈 답안은 응답 수에 포함하지 않습니다. 시험 점수는 별도로 저장하고 최근 시험의 답안·해설을 다시 열 수 있습니다. 기존 학습 기록은 유지됩니다.
- 신규 200문항에는 복수 정답 77개, 시각자료 28개, 실행 결과를 검증한 pandas 코드 해석 6개가 포함됩니다.

## 교수님 최종 대비

[최종 대비 페이지](https://creepc.github.io/BigDataProject_CBT/#/final)는 마지막 통합 정리 PDF 19쪽과 사용자가 전달한 시험 전 구술 필기를 함께 반영합니다. 기존 996문항·110개 학습 개념·학습 기록을 유지하고, 기본보다 한 단계 높은 중간 난도 120문항을 추가했습니다.

- 중간 난도를 처음 화면으로 표시합니다. 중간 1~3회는 각 40문항 모두 보통 난도이며, 비슷한 개념 비교·짧은 상황 판단·1~2단계 계산과 자료 해석을 연습합니다. 기본이나 고난도를 섞지 않습니다.
- 중간 120문항은 단일 정답 84개·복수 정답 36개·시각자료 15개입니다. 5V 보기는 영어 용어만 제시하고, 보기끼리 같은 개념 계열을 유지합니다. 발문·유형 배지·차트 주석에서 정답 정의를 미리 알려 주지 않도록 검토합니다. 선택지 해설은 간결하게, 개념·단계별 풀이·다른 예시는 자세하게 제공합니다.
- 기본 1~3회는 각 40문항·쉬움 20개·보통 20개로 그대로 보존합니다. 새 중간 난도와 기존 기본 다지기는 전부 핵심 범위입니다.
- 기본 다지기 120문항은 단일 정답 84개·복수 정답 36개·시각자료 15개이며, 발문은 최대 92자입니다.
- 기존 고난도 1~3회는 문항·정답·해설·회차 순서를 변경하지 않았습니다. 각 40문항·어려움 28개·보통 12개와 기존 보충 4개가 유지됩니다.
- 기본/중간 난도/기존 고난도/전체 360문항을 전환하며, 문제나 시험 해설에서 돌아올 때 원래 묶음을 유지합니다.
- 모든 고정 시험은 50분·문항당 2.5점이고, 해설 학습은 시간 제한 없이 한 문제씩 진행합니다. 기본이 너무 쉽다면 중간 난도만 선택해 학습·시험을 이어갈 수 있습니다.
- 기존 고난도 120문항에는 복수 정답 56개·시각자료 24개가 있습니다. 기본 다지기에도 복수 정답과 간단한 그래프 판독을 제공합니다.
- 19개 구술 강조 항목을 11개 주제로 연결하며, 주제별 개념 요약·구분할 점·원문 페이지·문제 학습을 제공합니다.
- PDF 중심·마지막 필기 강조·보충, 난이도·복수 정답·시각자료·미응답·최근 오답으로 고를 수 있습니다.
- 필터로 선택한 학습 묶음은 진입 시 고정하여 답안을 제출해도 현재 문제가 사라지지 않습니다.
- 실제 출제와 점수는 보장하지 않습니다. 가상 사례는 문항 안에 명시하고 카탈로그 구성과 시청 선호, 추천 후보와 추천 성과를 구분합니다.
- 근거 기록: `analysis/professor-final-source.json`, `professor-final-pages.json`, `professor-final-notes.md`. 출제 구성: `professor-final-review.json`, 세 `final-questions-*.json`·세 `foundation-questions-*.json`·세 `standard-questions-*.json`. 자동 커버리지: `professor-final-coverage.json`.
- 보존 검증은 기존 996문항 전체와 기존 최종 6회 메타데이터의 SHA-256을 자동 검사합니다. 이전 876문항 보존 검사도 유지합니다. `node scripts/audit-final-review.mjs 06dc3c9`로 기존 본문·개념·시험의 동일성도 확인할 수 있습니다.

## 로컬 실행

Node.js 24와 pnpm 11 기준입니다.

```bash
pnpm install
pnpm dev
```

프로덕션 검증:

```bash
pnpm content:build
pnpm test
pnpm typecheck
pnpm build
pnpm preview
```

Python 코드 예제의 실제 실행 결과를 확인하려면 pandas가 설치된 Python을 사용합니다.

```bash
node scripts/verify-lesson-code.mjs /absolute/path/to/python
```

## GitHub Pages 배포

1. 이 폴더를 GitHub 저장소의 `main` 브랜치에 push합니다.
2. 저장소의 **Settings → Pages → Build and deployment**에서 Source를 **GitHub Actions**로 선택합니다.
3. `.github/workflows/deploy-pages.yml`이 테스트와 빌드를 통과하면 Pages URL이 생성됩니다.

Vite `base`는 상대 경로(`./`)이고 라우팅은 URL hash를 사용하므로, 사용자 사이트와 프로젝트 사이트 모두에서 하위 경로 문제 없이 동작합니다.

## 데이터와 정확성

- 원본 강의자료는 `public/pdfs/`에 영문 파일명으로 복사해 정적 배포 시 안전하게 제공합니다.
- 전체 분석 기록은 `analysis/`에 보관하고, 학습 앱이 사용하는 정규화 데이터는 `src/data/courseData.ts`에 있습니다.
- 상세 본문은 `analysis/lessons-*.json`에 분리해 보관합니다. `pnpm content:build`가 시험 범위의 110개 개념과 원고를 연결하고 누락·중복·출처 범위와 제외 내용 재유입을 검사합니다.
- 새 학습형 문제는 `analysis/questions-*.json`에 보관합니다. 빌드가 개념별 4단계와 모든 학습 목표의 문제 연결을 검사하고 `analysis/question-coverage.json`에 커버리지 색인을 생성합니다.
- 신규 모의고사 문제는 `analysis/mock-questions-*.json`, 회차 설정은 `analysis/mock-exams.json`에 보관합니다. 빌드는 5×40 고유 문항·회차 중복·상세 해설·개념 전체 연결·출처를 검사하고 `analysis/mock-exam-coverage.json`을 생성합니다.
- 본문의 상황·수치 풀이·코드는 이해를 위한 학습 예시이며 강의 원본의 실제 관측 통계와 구별해 표시합니다.
- 강의자료에 직접 적힌 내용과 이해를 위한 보충 설명은 개념별 `evidenceType` 및 문항별 보충 표기로 구분합니다.
- `validateCourseData()`가 문항 ID 중복, 선택지 수, 단일·복수 정답 수, 출처·개념 참조를 검사합니다.
